# Boekerhouden

Eigen samenstel-applicatie voor Windows, vergelijkbaar met Visionplanner Compilation (Nmbrs Reporting).
De applicatie leest een administratie in (XAF-auditfile of Excel-proefbalans), rubriceert de
grootboekrekeningen naar jaarrekeningrubrieken (via een sjabloon, RGS of handmatig), begeleidt het
samenstellingsdossier met een werkprogramma, en genereert het financieel rapport.

**Status:** onderzoeks- en ontwerpfase. Zie [`docs/onderzoek`](docs/onderzoek/README.md).
